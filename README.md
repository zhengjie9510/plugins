# Plugins

简体中文 | [English](./README.en.md)

这是我在日常使用 AI 工具的过程中整理和维护的 Claude Code 插件集合，包含技能、MCP 服务以及来自社区的优秀实践。

仓库中的内容会根据实际使用持续调整；第三方内容会保留原作者、来源和许可证信息。下方还整理了一些值得关注的资源，方便后续查阅和筛选。

## 安装

在 Claude Code 中添加本仓库：

```text
/plugin marketplace add zhengjie9510/plugins
```

然后安装插件：

```text
/plugin install jason-agent-plugins@jason-agent-plugins
```
